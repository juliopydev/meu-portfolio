# Portfólio de Julio Cesar

Site de portfólio com quatro projetos, cada um em uma demonstração que você pode abrir e testar no navegador.

**Site no ar:** https://SEU-SITE.vercel.app
**GitHub:** https://github.com/juliopydev
**Contato:** jcesar.software@gmail.com

## Projetos

| Projeto | O que é | Pasta |
|---|---|---|
| Painel de pedidos | Quadro para acompanhar pedidos de um restaurante, da cozinha até a entrega | [projetos/painel-de-pedidos](projetos/painel-de-pedidos) |
| API de agendamentos | Playground de uma API que evita dois clientes no mesmo horário | [projetos/api-de-agendamentos](projetos/api-de-agendamentos) |
| App de finanças pessoais | Aplicativo para registrar gastos, definir metas e ver o mês em gráficos | [projetos/app-de-financas](projetos/app-de-financas) |
| Biblioteca de componentes | Documentação interativa de componentes de interface acessíveis | [projetos/biblioteca-de-componentes](projetos/biblioteca-de-componentes) |

Cada pasta tem um README próprio explicando o que o projeto faz, como testar e o que mudaria numa versão completa.

## Como rodar no seu computador

Não precisa instalar nada. Baixe ou clone o repositório e dê dois cliques no arquivo `index.html`.

## Estrutura

```
index.html                  portfólio (página inicial)
projetos/
  painel-de-pedidos/
  api-de-agendamentos/
  app-de-financas/
  biblioteca-de-componentes/
```

## Tecnologias

Estas demonstrações usam HTML, CSS e JavaScript puro em um único arquivo por projeto, sem dependências. Os dados são fictícios e ficam só no navegador. Cada README de projeto descreve a stack prevista para uma versão completa.

## Publicação

O site é publicado na Vercel a partir deste repositório. Cada alteração enviada para o GitHub atualiza o site automaticamente.

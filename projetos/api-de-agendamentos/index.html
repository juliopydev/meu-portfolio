Agenda da semana

Clique em um horário livre para preencher o exemplo de criação com ele.

    Endpoints

    Tudo em JSON, com códigos de status HTTP corretos.

    GET
    /horarios?dia=2Lista os horários livres de um dia (0 é segunda, 4 é sexta).
    GET
    /agendamentosLista todos os agendamentos.
    POST
    /agendamentosCria um agendamento. Devolve 409 e horários alternativos se o horário já estiver ocupado.
    DELETE
    /agendamentos/:idCancela e libera o horário.

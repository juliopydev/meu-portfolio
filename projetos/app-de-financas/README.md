# App de finanças pessoais (Bolso)

Aplicativo pensado para o celular, para registrar gastos, acompanhar um limite mensal e guardar dinheiro para metas.

## O que dá para fazer
- Ver o resumo do mês: saldo, receitas e despesas.
- Acompanhar o limite de gastos, que muda de cor ao se aproximar do limite.
- Ver os gastos por categoria (gráfico de pizza) e por semana (gráfico de barras).
- Adicionar e excluir lançamentos, com filtro de receitas e despesas.
- Criar metas e guardar valores nelas, com barra de progresso.
- Navegar entre meses (setembro e outubro de 2026 têm dados de exemplo).
- Alternar entre tema claro e escuro.

## Como testar
Abra o `index.html` no navegador (de preferência no modo celular das ferramentas do navegador). Toque no botão "+" para criar um lançamento.

## Tecnologias desta demonstração
HTML, CSS e JavaScript puro, com gráficos feitos em SVG. Os dados são fictícios e somem ao recarregar a página.

## Versão completa (planejada)
- Front-end em React com TypeScript.
- Supabase para banco de dados, login e sincronização entre aparelhos.

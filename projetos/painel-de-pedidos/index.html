Sobre este projeto

Projeto de portfólio para uma hamburgueria fictícia. Os dados são de exemplo e tudo roda no seu navegador.

  • Next.js
  • Node.js
  • PostgreSQL
  • Tempo real
  • Os indicadores e o faturamento por canal são recalculados a cada mudança.
  • A busca e o filtro de canal funcionam junto, sem recarregar a página.
  • Na versão completa, os pedidos ficam em um banco PostgreSQL e chegam por uma API em Node.js.

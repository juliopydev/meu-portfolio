# Biblioteca de componentes (Prisma UI)

Documentação interativa, no estilo do Storybook, de um conjunto de componentes de interface que serve a três produtos diferentes.

## O que dá para fazer
- Trocar entre três produtos (Casa Brasa, Hora Certa e Bolso) e ver os mesmos componentes mudarem de cores e de cantos.
- Testar cinco componentes: botão, campo de texto, alerta, interruptor e distintivo.
- Mudar as propriedades de cada componente e copiar o código gerado.
- Ler os pontos de acessibilidade de cada componente (por exemplo: role switch, aria-invalid e foco visível).
- Ver os tokens de design: cores, cantos, espaçamento e tipografia.
- Alternar entre tema claro e escuro.

## Como testar
Abra o `index.html` no navegador, troque o produto no topo e depois mude as propriedades do botão.

## Tecnologias desta demonstração
HTML, CSS e JavaScript puro. Os componentes leem tokens de design (variáveis CSS), por isso cada produto muda a aparência sem alterar o código dos componentes.

## Versão completa (planejada)
- Componentes em React com TypeScript.
- Estilos com Tailwind CSS.
- Documentação com Storybook e testes de acessibilidade automatizados.
